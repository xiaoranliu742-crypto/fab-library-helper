# Fab 免费素材助手

**作者：菊山（jushan） · 版本：1.5.3 · 许可证：MIT**

在当前 Fab 网页顶部显示一个可拖动、可收起的悬浮面板，批量将明确为零元的素材授权加入当前账号的素材库。

适合在 Quixel Megascans 卖家页、Fab 搜索结果或频道列表中领取免费素材。插件直接使用当前浏览器的 Fab 登录状态，无需 FabCLI，也无需安装 Node.js 才能使用。

## 功能

- 支持中文、英文页面，包括 `Free`、`From Free` 和中文免费标记。
- 两种范围：扫描当前网页卡片，或直接分页读取 Quixel 免费目录，不滚动、不请求缩略图。
- 整库模式按每页最多 24 项批量查询拥有状态；已确认拥有的项目无需逐项请求详情或价格。
- 整库模式按账号保存分页断点；正常项目处理完、失败项保存为待重试记录后才前进。刷新后恢复断点和待重试记录。
- 对没有本地拥有记录的素材查询账号状态，读取素材详情与每种授权的价格，只提交价格明确为零的授权。
- 入库后查询拥有状态，确认成功后才计入“已入库”。
- 可选择自动授权、Professional 或 Personal；无法核对所选授权时显示原因。
- 支持暂停、失败重试、JSON 结果导出和自动向下滚动。
- 支持 1、3、5、8、16、32 项同时处理，默认 3 项。各项独立核对价格、提交和确认，避免互相等待网络响应。
- 将确认拥有的项目按 Fab 账号保存在本地，再次遇到时直接跳过网络查询。
- 本页全部插件请求统一排队，启动时间至少间隔 1 秒；0.5、1、2、4、8 秒的领取后间隔另行计算。
- 429 限流时读取服务器冷却时间并保存到本浏览器；刷新后仍等待，冷却结束后手动继续。
- 只需要扩展的本地存储权限，内容脚本只运行在 `https://www.fab.com/*`。

> “入库”指加入 Fab 账号的素材库，不是下载文件，也不会把素材直接导入 Unreal Engine、Blender 或其他软件。插件是独立开发项目，不代表 Epic、Fab 或 Quixel 官方。

## 安装：Edge / Chrome

### 1. 获取并解压项目

在 GitHub 仓库页面点击 **Code → Download ZIP**，将压缩包完整解压。

解压后的目录类似：

```text
fab-library-helper-main/
├─ README.md
├─ preview.html
├─ extension/
│  ├─ manifest.json
│  ├─ core.js
│  ├─ content.js
│  ├─ popup.html
│  └─ popup.js
└─ tests/
```

**安装时要选择包含 `manifest.json` 的 `extension` 文件夹。** 不需要双击 JS 文件、`manifest.json` 或 `popup.html`。

如果拿到的是精简插件包，解压后直接看 `manifest.json` 位于哪个文件夹，选择那个文件夹即可。

### 2. 打开浏览器扩展管理页

- Edge：在地址栏输入 `edge://extensions`，回车。
- Chrome：在地址栏输入 `chrome://extensions`，回车。

打开页面上的 **开发人员模式**，点击 **加载解压缩的扩展**，选择上一步的 `extension` 文件夹。

安装成功后，扩展卡片显示 **Fab 免费素材助手**，版本为 **1.5.3**，详细信息中的作者为 **菊山**。面板和弹窗使用固定中文署名并标记为不自动翻译。请保留安装文件夹；以后移动或删除它可能导致扩展无法加载。

### 在 Edge 和 Chrome 同时安装

两个浏览器可以加载同一份 `extension` 文件夹。分别打开各自的扩展管理页、加载文件夹，并在各自浏览器登录 Fab。代码共用一份，登录、设置和本地进度由各浏览器分别保存，不自动同步；使用同一 Fab 账号时，服务器素材库相同。更新共用文件夹后，两个浏览器都要分别重新加载扩展并刷新网页。

### 3. 刷新 Fab 网页

如果正在使用另一个同类插件，先将它停用，以免重复操作。然后打开或切换到 Fab，按 **Ctrl + R** 刷新。

顶部应该出现“Fab 免费素材助手”胶囊或展开面板。如果未展开，点击胶囊；也可以点击浏览器工具栏的扩展图标，再点“显示 / 展开当前网页面板”。

## 第一次使用

1. 在**当前 Edge / Chrome 浏览器**登录 Fab。其他浏览器或 FabCLI 的登录状态不会自动共享。
2. 打开 [Quixel Megascans 卖家页](https://www.fab.com/sellers/Quixel%20Megascans)，或其他 Fab 素材列表。
3. 检查“处理范围”。Quixel 全库模式直接读取目录，按下一节操作；当前网页模式需等待卡片加载，再检查“当前网页 · N 项”。这个数字不是已确认免费的数量，也不是商店全库总数。
4. 在“领取授权”中选择需要的授权。“自动”只在明确为零元的授权中选择；如果能匹配到零元的 Professional，会优先选择它。
5. “同时处理”选择 **3 项 · 并发快速**，“领取后间隔”可用 **0.5 秒 · 快速**。这是每项完成后的等待；另外，本页所有插件 HTTP 请求启动时间至少间隔 1 秒。并发数不等于每秒请求数，也不保证不会限流。
6. 当前网页模式如需处理下方内容，勾选“自动向下滚动”；Quixel 全库模式无需滚动，自动读取后续目录页。
7. 点击 **开始入库**。先识别 Fab 账号，复用该账号已确认拥有的本地记录，其余项目再核对拥有状态、详情、授权价格，随后提交免费入库并确认结果。
8. 需要停止时点击 **暂停**。停止取出新项目，正在核对但未提交的项目返回待处理；已提交的项目会继续核对结果，所有在途任务结束后才可继续。

Fab 如果要求接受授权条款、完成登录或网页验证，请在原网站自行完成。可以先手动领取一项免费素材，让网站完成必要的授权流程，再回到插件重试。插件不自动接受 EULA，也不处理验证码。

## Quixel 整库：低内存处理

目录固定按标题排序，以避免旧版类型权重排序在约 5024 项处返回重复分页。首次从 v1.5.0 升级时会重建一次目录位置，保留全部已拥有记录；重读目录页不等于重新领取，已记录项目跳过状态、详情、价格和领取请求。新的标题分页断点可正常跨刷新续扫。

1. 先暂停旧任务，更新并重新加载扩展，然后刷新 Fab。这会释放旧页面累计的素材卡片，保留扩展的本地拥有记录。
2. 在“处理范围”选择 **Quixel 全库 · 低内存**。Quixel 卖家页默认选择此模式；已经保存的范围设置优先保留。这个范围明确指 Quixel 免费目录，不跟随网页上的分类或其他筛选条件。
3. 保持 Fab 列表偏好设置中的“显示素材库中的产品”开启。如果隐藏已拥有项目，领取会让分页目录发生位移，插件会提示停止；请在网站自行打开该选项。运行期间不要改变此设置。
4. 选择授权和并发，点击 **开始入库**。截图出现限流时，先等待，再用较低并发和较长间隔继续；32 项是可选任务上限，不代表更高的实际吞吐量。
5. 插件读取一页、处理一页，再继续下一页。直接读取目录中的编号和标题，不自动滚动网页，不为整库创建卡片或请求缩略图。网页自身最初显示的内容仍由 Fab 加载。
6. 本地已确认的项目直接跳过网络核对；其他项目先批量查询拥有状态。只有无法确认已拥有的项目才继续逐项核对拥有状态、授权价格并入库。
7. 暂停后点击“继续入库”接着处理。刷新或关闭网页会结束任务；再次开始时，按当前账号恢复已完成页面的断点，中断那页重新读取并复用拥有记录。不会自动开始运行。
8. 普通单项报错（如 HTTP 404 / 500、价格结构无法识别）保存为待重试记录后继续后续目录，不计为入库成功。失败项优先显示，可查看其下方的具体原因；点击 **重试失败** 只重试这些项目，不重新扫描已完成目录。目录读完但仍有失败项时，主按钮会变为 **重试未完成**。
9. 到达接口返回的目录末尾后结束。新上架、价格变化或希望复查时，点击 **从头检查**：只重置目录断点，保留已确认拥有记录。遇到登录失效、网页验证、限流、未处理完的项目或待重试记录保存失败，停止并保留本页断点。目录请求失败也不会跳过整页。

该模式减少网页卡片与图片累积，并减少大量已拥有素材的逐项查询；不保证固定内存占用、固定速度或目录在运行期间保持不变。本轮只保留精简文本结果，导出包含本次打开网页后遇到的项目与恢复的待重试记录，不补回刷新前的完整统计。分页过程中新增的素材可在完成后从头复查。目录请求之间留有间隔；限流仍暂停，不自动反复请求。

## 能否一次获取整个素材库？

点击一次“开始入库”可以自动处理队列，但当前实现仍需为每项新素材独立调用入库接口。并发模式把所选数量的网络等待重叠处理，最高 32 项；不会将几万个素材合成一个请求，也不保证能同时提交全部素材或固定提速倍数。32 是本版可选的任务数量上限，不是实测的 Fab 服务上限。并发越高不保证越快，Fab 可能限流。

如需使用 32 项：暂停并等待在途任务结束，将“同时处理”改为“32 项”后继续。更新时保留原来选择的并发数和本地拥有记录，不会自动把 8 项改成 32 项。若触发 429，任务暂停并显示冷却倒计时；冷却结束后手动继续。降低并发不能立即解除服务端限制。

网页模式的队列来自已加载链接。Quixel 整库模式直接分页读取免费目录，可以一次点击持续处理到接口返回的末尾。两种模式都没有把几万个素材合成一个领取请求；当前没有核实可用的官方整库领取端点。

### 请求节奏与限流冷却（v1.5.3）

同一网页的账号、目录、批量状态、详情、价格、提交与结果确认请求共用一个队列，请求启动时间至少间隔 1 秒，排队时间不计入网络超时。多个任务仍可等待各自的响应；本机制不协调其他插件、标签页或浏览器的网络请求。

收到 HTTP 429 时，未发出的普通请求取消排队；优先按响应的 `Retry-After` 秒数或 HTTP 日期等待。服务器没有提供可用值时，本插件暂用 60 秒作为本地冷却，并非 Fab 公布的重置时间。冷却时间保存到当前浏览器扩展存储，刷新页面或清除拥有记录不会绕过它；按钮显示倒计时，结束后只恢复手动操作，不自动重试。Edge / Chrome 的冷却存储各自独立。

Fab 的具体配额、计数范围和恢复时间没有在此项目中得到核实，1 秒间隔也不是保证安全的官方速率。若多个领取插件、标签页或浏览器都在请求，仍可能叠加请求负载；排查时仅运行一个浏览器中的一个领取任务，等待冷却后再继续。不要用清除本地记录处理限流，这反而会增加重新查询。

所有并发任务共用停止状态。任何一个请求检测到 401、403、429 或网页验证异常，立即停止取新项目和后续未提交的入库；已经发送的请求无法撤回，会等待其响应，已提交入库的项目在普通暂停时继续确认结果，限流冷却期间不发送确认请求，之后重试先查询拥有状态。不自动重试限流请求。

## 自动滚动和运行范围

- 以下滚动规则只适用于“当前网页”范围；整库模式不使用滚动。
- **不勾选自动滚动**：处理当前页已经加载的素材；你可以手动向下滚动后点击“重新扫描”。
- **勾选自动滚动**：处理已知队列后，向下滚动等待更多卡片，再继续处理。
- **没有“下一页”按钮自动点击功能**。自动滚动主要适用于无限滚动列表。
- 连续 5 次滚动未发现新链接时结束本轮。这不保证已覆盖卖家或商店的全部素材；网络较慢时可以再滚动、扫描一次。
- 切换卖家、页面或搜索条件时，停止上一页任务并重新扫描当前页。

## 后台、暂停与数据保存

- Fab 标签页必须保持打开。切到后台通常仍能运行，但浏览器可能节流或休眠，使任务减速或暂停。
- 当前版本没有独立后台任务服务；关闭网页、退出浏览器或电脑休眠后不会持续执行。
- 暂停或收起面板不会删除已入库素材。
- **刷新 / 关闭网页会结束任务，并清空本页的结果统计。** 需要保留记录时先导出结果。
- 已成功入库的素材保存在你的 Fab 账号里。v1.3.0 起，同时在扩展本地存储中保存该账号下已确认拥有的素材编号、确认时间与结果类型。
- 下次开始会请求一次账号身份，已记录的素材直接显示“本地记录：此前已确认拥有”，跳过状态、详情、价格和入库请求。未记录的项目照常核对；失败、付费和待处理项目不会被记为已拥有。
- **旧版本没有保存的历史项目，首次升级后仍需查询一次。** 本版不能凭旧截图恢复素材编号，也没有导入旧 JSON 的功能；查询确认后会记住，之后不再反复请求。
- 本地拥有记录不保存完整页面队列、滚动位置或自动运行任务。网页模式刷新后列表仍要重新加载 / 滚动；整库模式另存分页断点，无需滚动回原位置。两者的本轮统计都会重新计数，已记录素材不会逐项联网重查。
- 本地记录是此前确认的结果；如果素材退款或需要重新核实，可先暂停，再点击“清除本地记录”后开始。这会同时删除当前账号的目录断点，不影响账号资产。待重试记录也会一并清除。它不会释放 Fab 网页已经加载的卡片内存。
- **Edge、Chrome 及各自的浏览器配置文件独立保存本地拥有记录、分页断点和设置，不自动合并。** 面板记忆栏会显示 Edge / Chrome；清除某一浏览器的记录不会清除另一浏览器。若两边登录同一个 Fab 账号，服务器素材库仍是同一份，已入库资产会在两边显示。
- 更换 Fab 账号时不复用另一个账号的记录；无法识别稳定账号编号或读取本地存储失败时，回退为正常联网核对。界面会显示原因。
- 授权选项、间隔、并发数、处理范围和自动滚动设置保存在扩展本地存储中。
- 网页原卡片的“已入库”标记可能要刷新才会更新，以插件实际查询的拥有状态为准。

## 更新插件

1. 暂停任务，先导出需要保留的结果。
2. 将新版本插件文件放到原来加载的文件夹中。保留同一路径可以减少重新安装步骤。
3. 在 `edge://extensions` 或 `chrome://extensions` 点击本插件的 **重新加载**。
4. 回到 Fab，按 **Ctrl + R** 刷新。
5. 检查版本和设置。原有操作间隔和并发选择会保留；确认面板显示 v1.5.3 以及每页统一请求间隔提示。

如果改用了全新的文件夹路径，请停用旧扩展，再用“加载解压缩的扩展”选择新文件夹。

## 常见问题

| 情况 | 处理方法 |

| 看不到悬浮面板 | 确认插件启用，当前网址是 `https://www.fab.com/`；刷新网页后再打开面板 |
| 扫描显示 0 项 | 等素材卡片加载，再点“重新扫描”；购物车、账号页等通常没有可处理的列表 |
| 有付费素材混在列表里 | 会按授权价格核对；未找到明确零元授权的项目会跳过 |
| HTTP 401 | 在当前浏览器重新登录 Fab |
| HTTP 403 / 缺少验证信息 | 在 Fab 手动领取一项免费素材，完成网站要求的授权或验证，再重试失败项 |
| HTTP 429 / 请求限流 | 停止新请求，保存冷却时间并显示倒计时；结束后手动继续。先停用其他领取任务；清除记录不能解除限流 |
| 已提交但未确认拥有 | 不计为成功，保存待重试记录；稍后点击“重试失败”，先查询拥有状态 |
| 单项返回 HTTP 400 | Fab 拒绝了该项请求，无法仅凭状态码确定原因；失败项单独保存，继续其余目录，再到素材详情页核对授权或稍后单独重试。清除本地记录不会修复服务器拒绝 |
| 一项报错后无法继续目录 | 更新到 v1.5.3 并重新加载扩展、刷新 Fab；普通单项失败保存后继续目录，失败项置顶显示；若提示待重试记录保存失败，保留本页断点并检查扩展存储 |
| 价格或拥有状态结构无法识别 | 不会继续提交该项；网站接口可能发生变化，请记录错误并反馈 |
| 速度慢 | 在前台保留页面，选 3 项并发和 0.5 秒档；真实速度还取决于网络、Fab 响应和限流 |
| 网页内存占用大 | 先暂停，再刷新或关闭该标签页；使用 Quixel 全库低内存范围，避免继续累积卡片和图片 |
| 如何删插件缓存 | 暂停并等待当前请求结束，再点“清除本地记录”；这会删除当前账号的拥有记录和断点，下次重新核对，账号库不变 |
| 希望从头扫描但保留已有记录 | 在整库模式点“从头检查”，不要清除本地记录 |
| 提示分页会移位 | 在 Fab 列表偏好设置中开启“显示素材库中的产品”，运行期间保持开启 |
| 刷新后统计变成 0 | 这是本页统计；已入库素材仍在账号库里。刷新前可导出 JSON |

## 隐私与授权

详细说明见 [PRIVACY.md](PRIVACY.md)。

插件只在 Fab 域名下读取素材链接和页面状态，并通过同源请求使用当前网页会话。写入操作只有免费入库接口，没有付款流程。不记录、导出密码、Cookie、会话令牌，也不读取 FabCLI 的本地凭据文件。

没有第三方后端、分析统计或遥测服务。JSON 导出由用户主动触发，内容是素材处理结果，不包含认证信息。素材的可用范围由对应的 Fab 授权决定，插件本身不授予额外使用权。
