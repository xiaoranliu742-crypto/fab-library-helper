# Fab 免费素材助手 v1.5.7

作者：**菊山（jushan）** · MIT License。完整中文使用说明见项目根目录的 README.md。

这是为当前 Fab 网页编写的独立浏览器扩展，兼容 Edge / Chrome。顶部深色胶囊可拖动、收起、展开，处理过程中显示进度。

## 安装

1. Edge 地址栏打开 `edge://extensions`（Chrome 用 `chrome://extensions`）。
2. 开启“开发人员模式”，点击“加载解压缩的扩展”。
3. 选择本文件所在文件夹，即包含 `manifest.json` 的文件夹。
4. 关闭旧版同类扩展，回到 Fab 网页刷新一次。
5. Fab 网页顶部会出现“免费素材，一键入库”面板。工具栏图标可重新展开面板。

## 更新 / 并发提速

要启用本版极速配置：先暂停并等待任务结束，重新加载扩展并刷新 Fab，然后点击面板的“一键极速”，再点击开始 / 继续。该按钮设置 0.1 秒请求间隔、16 项并发、领取后 0 秒额外等待，保留进度与其他选项，不自动开始任务。升级本身保留旧设置，所以要点击此按钮或手动调整；也可先试 0.25 秒档。

如果将新版本文件覆盖到原来加载的文件夹：先暂停当前任务并导出需要保留的结果，再在 `edge://extensions` 中点击本插件的“重新加载”，然后刷新 Fab 网页。首次从 GitHub 下载时，请选择解压后包含 `manifest.json` 的 `extension` 文件夹。

- 支持 1、3、5、8、16、32 项并发，默认 3 项，原有选择会保留。要用 32 项，暂停并等在途任务结束后，手动选择“32 项”再继续。更高并发不保证更快，仍受 Fab 响应和限流影响；遇到 429 时暂停，当前请求结束后可手动继续，不强制倒计时；降低并发不能立即解除服务端限制。
- “本轮新增”显示本页提交并确认成功的数量；“已拥有总计”随扫描实时增加，包含联网确认已有、本地记录恢复和本轮新增，按编号去重。两栏不能相加算进度；下方本地记忆是历史记录数。
- 新增按 Fab 账号保存的本地拥有记录，再次遇到已确认项目时直接跳过网络查询。
- 原有间隔设置会保留，更新后可自行选择“0.5 秒 · 快速”。该间隔是每项完成后的等待；另外，本页全部插件 HTTP 请求统一排队，“请求间隔”可选 0.1、0.25、0.5、1、2 秒，默认 0.5 秒；领取后间隔新增 0 秒。
- 各项分别核对价格和提交；最新详情编号匹配、授权价格完整时直接复用，否则再查询独立价格接口。整库合并本页提交后的拥有状态确认，减少请求；所有请求仍受本页统一队列约束。并发只重叠网络等待，没有把整个素材库合成一个入库请求。
- 已拥有、没有零元授权的项目只等待最多 0.1 秒，避免为跳过的项目消耗完整领取间隔。
- 已知队列处理完后才重新扫描网页，同一次扫描复用卡片祖先结构，减少素材较多时的重复计算。
- 任何任务遇到 401、403、429 或网页验证异常，所有任务立即停止取新项目和未提交的入库，等待在途请求结束。已经发送的请求无法撤回；普通暂停时已提交的项目继续确认结果，限流停止时不发新的确认请求，之后先核对拥有状态。
- 429 仍暂停任务并将请求间隔调慢一档（0.1 → 0.25 → 0.5 → 1 → 2 秒）。取消默认 60 秒冷却、倒计时和按钮锁定；Retry-After 只作 Fab 等待建议显示，无有效值时不设置时间。用户手动继续，不自动重试，Fab 本身仍可能返回限流。升级仅清理旧冷却标记，拥有记录与断点保留。
- 本页队列不协调其他插件、标签页或浏览器；排查限流时只运行一个领取任务。Fab 的具体配额尚未核实，统一间隔不保证避免限流。不能据固定间隔推算真实领取速度，网络响应、后台节流和网站限流都会影响耗时。

## 使用

### Quixel 全库低内存模式（v1.5.7）

- 同一账号的本地已拥有记录直接跳过状态、详情、价格和领取请求。当前网页明确的 Saved in My Library / 已入库状态，账号和页面会话匹配后也直接计入已拥有并记住；标题文字不算状态标记。
- 刷新网页回到顶部不代表后台从首页开始。点击继续后按账号恢复保存游标，显示本次起始断点和累计页数。目录仍需读取编号，已知拥有项目直接通过。
- 断点或本地记录读取异常时停止，不再静默从第一页重扫；重试会重新读取。保存失败也停止，不继续累积无法恢复的进度。只有主动从头检查或旧 v1 排序断点迁移才重建目录。

- 移除目录页完成后额外固定的 0.5 秒等待，下一页仍经过统一请求队列；断点和失败记录保存顺序不变。
- 0.1 秒约每秒启动最多 10 次请求；在不含网络的模拟时钟中，51 次请求的首尾调度间隔从 25 秒缩为 5 秒。实际领取速度未实测，受网络和限流影响；极速只更改速度设置，不自动重试限流任务。

- 一页最多 24 项，提交后先显示“待确认”，合并查询拥有状态后才增加新增与已拥有数量、保存记录。批量缺失或异常时回退逐项核对；仍未确认会保留失败记录。暂停时继续确认已提交项，限流时停止新请求并保留断点。
- 完整价格、全新素材、一次确认且无重试的 24 项离线场景，相关请求由 98 次降至 51 次，账号识别另计；这不是实际 Fab 的领取速度实测。原间隔和断点保留，无需清记录。

- 普通单项失败等待 1.5 秒自动重新核对并尝试一次，仍失败才保存待重试记录并继续目录。扫描再次遇到历史失败项会自动复核；限流、登录失效和验证仍暂停。失败项优先显示，点击“重试失败”只重试这些项目；目录读完仍有失败时，主按钮显示“重试未完成”。刷新后待重试记录仍保留。
- 登录失效、网页验证、限流、目录页请求失败或待重试记录保存失败仍会暂停，不跳过整页，也不自动反复重试。

- 修复旧版约 5024 项处重复断点导致无法继续的问题，目录改为按标题稳定排序。旧版升级后重建一次目录位置，已拥有记录全部保留，重读目录不会重新领取这些素材。
- Edge 和 Chrome 的本地记录、目录断点与设置分别保存在各自浏览器；记忆栏显示当前浏览器，不自动合并。相同 Fab 账号的线上资产会正常共享。

- 在“处理范围”选“Quixel 全库 · 低内存”，点击一次开始后直接分页处理免费目录，不滚动、不请求目录缩略图；此范围不跟随网页上的分类筛选。
- 按每页最多 24 项批量核对拥有状态；已有的直接计入总数，明确未拥有的复用本页结果，省去重复状态查询。缺失或无效状态仍逐项核对，零元价格和提交结果校验均保留。
- 正常项目完成且失败项已保存待重试记录后按账号推进断点；暂停、限流、目录请求失败或存储失败时保留中断页。刷新或关闭网页后需再次点击开始，从断点继续，不必滚动回原位置。
- “从头检查”只重置断点，保留已拥有记录。目录发生新增或价格更新后可从头复查。运行期间保持 Fab 偏好设置中“显示素材库中的产品”开启，避免隐藏已拥有项目造成分页移位。
- “清除本地记录”删除当前账号的本地拥有记录和目录断点，不删除 Fab 资产。要释放旧页面内存，先暂停再刷新或关闭标签页；清记录不能释放网页卡片内存。
- 仅保留编号、标题等文本结果，列表显示最近项目；不保证固定内存占用或速度。整库仍逐项入库，不是一个请求瞬间领取全部。
- Quixel 卖家页默认用整库范围，已保存的范围设置优先。以下卡片扫描与自动滚动说明仅适用于“当前网页”范围。

- 在当前浏览器登录 Fab。无需安装或登录 FabCLI。
- 打开 Quixel 卖家页、搜索页或频道列表。等待卡片加载。
- 面板显示扫描到的素材链接数量；这是待核对项目数，不是免费素材总数。
- 点击“开始入库”后逐项核对：先查询已拥有状态，再读取素材详情和每种授权的价格，只提交价格明确为零的 offer。
- “自动”仅选择明确为零元的授权；若存在映射明确且价格为零的 Professional，会优先选择它。也可明确指定 Personal / Professional；无法核对所选授权时不会静默换成另一授权。
- “暂停”阻止取出新项目，正在核对且未提交的项目返回待处理；已经提交的项目继续核对拥有状态，等待所有在途任务结束后才可继续。
- 选择“当前网页”时只处理已加载的素材。勾选“自动向下滚动”后继续加载当前列表。连续 5 次滚动未发现新链接时结束本轮；这不保证已覆盖整个商店目录。
- 网页切换卖家或搜索条件时，停止上一页任务并重新扫描。
- “重试失败”先核对拥有状态，不直接重复提交；“导出结果”保存本轮项目状态到本地 JSON。
- 刷新或关闭网页会停止任务并清空本页统计；已确认拥有的记录保存在本浏览器扩展存储中，下次开始识别同一账号后直接跳过这些项目。失败、待处理项目不作为已拥有记录，普通失败另存待重试记录。
- 旧版没有保存的历史项目首次升级后仍需查询一次，确认后本版会记住。网页模式列表仍需滚动加载；整库模式保存目录断点。不恢复滚动位置或自动运行，也不能导入旧 JSON。需要完整本轮结果时先导出。
- “清除本地记录”清除当前账号的本地拥有记录和整库断点，不影响 Fab 账号素材。之后重新开始会联网核对，可用于退款或需要重新核实的情况。
- 同一文件夹可分别加载到 Edge 和 Chrome；分别登录，各浏览器的设置和本地进度独立保存。无法识别账号编号或读取本地存储失败时会显示提示并回退为联网核对。
- 批量操作时请保留此网页，浏览器可能降低后台标签页的执行速度。网页原有卡片的“已入库”标记可能需要刷新后更新，以面板查询到的拥有状态为准。

## 出错处理

- 未出现面板：确认扩展启用，且当前网址为 `https://www.fab.com/`，然后刷新。
- 未发现素材：等待素材卡片加载，点击“重新扫描”。支持 `Free`、`From Free`、中文页面；不会仅凭这些文字提交领取。
- HTTP 401：在当前浏览器登录 Fab。FabCLI 的登录不会自动登录 Edge。
- HTTP 403 或缺少验证信息：在 Fab 手动领取一项免费素材、完成网站要求的授权或验证后，再点击“重试失败”。本扩展不自动接受 EULA、完成验证码或绕过网页验证。
- HTTP 429：Fab 请求限流，任务暂停。当前请求结束后可手动继续，无强制冷却倒计时；服务端等待建议仅作提示，不能解除 Fab 自身的拒绝。
- 提交后未确认拥有：不会记作成功。整库会批量核对最多三轮，缺失或异常结果逐项回退；仍失败则保留记录，稍后单独重试会先查询拥有状态。
- 提交返回 400：会重新查询拥有状态，只有确认已拥有才计数；否则仍按失败处理，不能保证自动修复服务端拒绝。

## 权限与实现

仅在 `https://www.fab.com/*` 注入内容脚本，扩展 API 权限只有 `storage`。使用当前网页的会话向 Fab 同源接口请求；不请求读取其他网站、密码管理器或 FabCLI 本地令牌的权限。不保存、导出 Cookie 或密码，无遥测或外部服务器，无付款接口。

本地开发版，非 Epic 官方产品。Fab 内部接口可能变化。使用网站授权条款仍适用，插件不会扩大素材使用权。

使用离线模拟网页验证扫描、授权价格保护、暂停、入库确认、详情价格复用、批量结果确认和页面切换等流程。测试不请求真实 Fab 服务，不能据此保证网站内部接口长期兼容，也没有承诺固定领取速度。

开发测试：在项目根目录执行 `npm ci --ignore-scripts`、`npm test`（Node.js 22+）。直接安装插件无需 Node.js 或 FabCLI。
