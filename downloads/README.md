# 直接安装包

[下载 Fab 免费素材助手 v1.5.8](https://github.com/xiaoranliu742-crypto/fab-library-helper/raw/refs/heads/main/downloads/fab-library-helper-v1.5.8.zip)

1. 将 ZIP **完整解压到单独文件夹**。
2. 在 Edge / Chrome 扩展管理页开启“开发人员模式”，点击“加载解压缩的扩展”。
3. 选择解压后直接包含 `manifest.json` 的文件夹。

这个安装包没有额外的 `extension` 嵌套目录。包内包括完整使用说明、简明安装步骤、隐私说明和许可证。功能版本仍为 1.5.8。

不要将 GitHub 自动提供的源码 ZIP 当成这个安装包；源码包仍需选择其中的 `extension` 文件夹。

开发者可在仓库根目录运行 `npm run package` 重新生成，旁边的 `.sha256` 文件用于核对安装包完整性。
